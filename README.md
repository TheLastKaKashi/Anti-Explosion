## Blocked Items

| Item | Status |
|------|--------|
| TNT | ❌ Blocked |
| Underwater TNT | ❌ Blocked |
| Lava | ❌ Blocked |
| Flint and Steel | ❌ Blocked |
| End Crystal | ❌ Blocked |
| Fire Charge | ❌ Blocked |

## Features

- Protects your builds from explosions, fire and lava griefing
- Simple configuration
- Lightweight and fast

## Installation

1. Download the latest `.phar` from the [Releases](../../releases) page.
2. Put it in your server's `plugins/` folder.
3. Restart the server.

## Configuration

Edit `plugin_data/AntiExplosion/config.yml` after the first run.
